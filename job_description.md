# AI Intern – Workflow Automation

**Location:** Remote / Hybrid (India)
**Duration:** 6 months, with possible full-time conversion
**Team:** AI Operations

## About the role

We are looking for an AI Intern who loves automating boring work. You will build
workflows that connect large language models (mainly Claude) to everyday business
tools like Gmail, Google Sheets, Slack and CRMs. You will prototype in no-code /
low-code tools such as n8n, Make and Zapier, and write Python when a workflow needs
custom logic.

## What you will do

- Design and build automation workflows in n8n, Make or Zapier
- Call LLM APIs (Claude / Anthropic API) to classify, summarise and extract data
- Write prompts that return reliable, structured output (JSON)
- Write small Python scripts to test prompts, clean data and call REST APIs
- Connect services using webhooks, OAuth credentials and HTTP requests
- Handle errors: retries, timeouts, invalid model output
- Document your workflows so non-technical teammates can use them

## Must-have skills

- Python basics (functions, lists/dicts, reading files, `requests` or an SDK)
- Understanding of REST APIs, JSON, HTTP methods and API keys
- Hands-on experience with at least one LLM API (Claude preferred)
- Prompt engineering for structured output
- At least one automation tool: n8n, Make or Zapier
- Git and GitHub

## Nice-to-have skills

- Google Workspace APIs (Gmail, Sheets, Drive)
- Webhooks and event-driven workflows
- Basic SQL or spreadsheets for data handling
- PDF / document parsing
- Deploying small apps or bots (Streamlit, FastAPI, Docker)

## What we look for

- 1–2 projects that show you automating a real task end to end
- Clear written communication (README, comments, short explanations)
- Curiosity and the habit of testing your own work

## Education

Pursuing or recently completed B.Tech / B.E. / BCA / MCA / B.Sc in Computer Science,
IT, Data Science or a related field.
